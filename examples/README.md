# 示例 DXF

本目录收录由 `envcad` 生成的代表性国标工程图，可直接用 AutoCAD / ZWCAD / 浩辰 / 中望 打开，
验证制图规范（图框标题栏、国标图层、标高/管径/坡度/流向标注、技术要求）落实情况。

| 文件 | 行业 | 说明 |
|------|------|------|
| `T2_竖流斜管沉淀池平剖面图.dxf` | 给排水 / 环保 | 竖流斜管沉淀池平剖面：D6m / 总高 5.5m / 污泥斗 / 斜管 / DN300 进水 / DN150 排泥 |
| `T4-01_总平面布置图.dxf` | 环保 | 50m³/d 生活污水处理站总平面布置（成套项目 6 张图中的总图） |
| `01_填埋场剖面图.dxf` | 固废 | 卫生填埋场剖面：库容 / 防渗衬层 / 渗滤液导排 |
| `10_曝气池.dxf` | 环保 | 曝气池工艺图 |
| `T3_污水自流管网平面布置图.dxf` | 给排水 | 污水自流管网平面：DN350 HDPE / 0.3% 坡度 / 闸阀·软接头·流量计 / 穿墙套管 |

## 重新生成

```powershell
pip install -e ".[all]"          # 安装插件
envcad all --out examples        # 重新生成全部验收测试图到 examples/
envcad t2 --out examples         # 或仅生成单张
```

> 这些示例图已随仓库提交；如需更新，重新运行上述命令后 `git add examples/` 即可。
